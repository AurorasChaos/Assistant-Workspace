# Community events dashboard — final specification

This is a fictional example artifact.

## Outcome

The coordinator sees actionable event exceptions first, can preserve context while registering a guest, and sees capacity/access consequences before confirmation.

## Accepted experience

1. The dashboard leads with events needing attention.
2. Programme totals remain a compact orientation strip.
3. Selecting an event updates the adjacent detail pane.
4. Registration retains the selected event context.
5. Every registration receives a lightweight preview.
6. Capacity or layout effects receive stronger warning treatment.

## Build gate

Acceptance of this document and its Final Review does not authorize implementation. The reviewer must be asked separately whether to begin.
