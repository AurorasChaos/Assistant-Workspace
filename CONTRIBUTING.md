# Contributing

Contributions should keep the workbench dependency-light, accessible and safe to point at private content.

1. Create a branch.
2. Add or update tests/validation for schema changes.
3. Run `npm test`.
4. Test the fictional prototype both normally and with annotation mode enabled.
5. Explain any manifest or URL compatibility change in the pull request.

Do not submit real customer records, internal URLs, credentials or private review output as examples.
